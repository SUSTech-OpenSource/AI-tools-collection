# Remio

### 官网

[Remio](https://remio.ai/) 是一款本地优先的 AI memory 和个人知识库桌面应用，可以把文件、网页、录音、邮件、消息、图片和笔记等资料解析成本地索引和向量。

### 适合场景

* 资料分散在本地文件夹、网页、邮件、会议记录和聊天消息中，需要统一检索。
* 希望让 AI 或 agent 先拿到精准上下文，而不是反复读取整个文件夹或把大段文档塞进 prompt。
* 需要更快地从多种文件格式中找资料、总结内容、回溯来源。

### 特点

* 支持多种文件和内容格式解析，包括文件、网页、录音、邮件、消息、图片和笔记。
* 通过本地索引和向量检索减少临时扫描文件、逐个打开文档、使用 grep 查找内容的成本。
* 先检索聚焦上下文，再交给模型处理，从而节省 token 和调用成本。

### 使用说明

Remio 需要安装桌面客户端；如果本机没有安装客户端，应先从官网下载安装。
